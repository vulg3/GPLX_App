# 🚗 GPLX App - Ứng Dụng Học Bằng Lái Xe

## ✨ Tính Năng Nổi Bật

### 📚 Học Tập

- ✅ Học câu hỏi theo danh mục có phân loại rõ ràng
- ✅ Hiển thị đáp án đúng với giải thích chi tiết
- ✅ Đánh dấu câu điểm liệt (sai 1 câu là trượt)
- ✅ Hỗ trợ hình ảnh biển báo và sa hình

### ✍️ Thi Thử

- ✅ Đề thi 25 câu đúng cấu trúc chuẩn
- ✅ Timer đếm ngược 19 phút
- ✅ Điều hướng giữa các câu linh hoạt
- ✅ Theo dõi tiến độ real-time

### 📊 Kết Quả

- ✅ Xem kết quả chi tiết với phân tích
- ✅ Review từng câu trả lời
- ✅ Lịch sử 50 lần thi gần nhất
- ✅ Thống kê chi tiết

### 🎨 UI/UX Modern

- ✨ Beautiful gradients everywhere
- 💫 Smooth animations with React Native Reanimated
- 🎊 Confetti celebration khi đạt
- ⚡ Instant feedback cho mọi action
- 🎭 Professional design

## 🎯 Hỗ Trợ Loại Bằng

### 🏍️ Bằng A / A1 (Xe máy)

- Xe mô tô hai bánh
- Xe mô tô ba bánh
- Xe gắn máy
- ~200+ câu hỏi

### 🚗 Bằng B / B1 (Ô tô)

- Xe ô tô con (≤ 8 chỗ)
- Xe ô tô tải nhỏ (≤ 3.5 tấn)
- ~400+ câu hỏi

## 🚀 Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run the app
npm run android  # Android
npm run ios      # iOS
```

## 📦 Tech Stack

- **Framework**: React Native + Expo
- **Navigation**: React Navigation Stack
- **Animation**: React Native Reanimated 3
- **UI**: Custom components with Linear Gradient
- **Storage**: AsyncStorage
- **Language**: TypeScript
